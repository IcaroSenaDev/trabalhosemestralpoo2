PROJETO POO - BIBLIOTECA

Projeto Java pronto para importar no Eclipse.

1) File > Import > Existing Projects into Workspace
2) Selecione a pasta biblioteca_final extraída
3) Abra src/Programa.java e execute (Run As > Java Application)

Prazo de devolução: calculado automaticamente como 7 dias corridos após o empréstimo.
A tabela de empréstimos exibe a data de empréstimo, data prevista e situação.

O relatório completo está em RELATORIO_APRESENTACAO.md.

Recomendação: use codificação UTF-8 e Java 17 ou superior.
